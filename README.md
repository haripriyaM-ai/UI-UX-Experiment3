## Aim:

To analyze and compare the user experience of existing applications, Netflix and Duolingo, identify their usability features and design patterns, and incorporate the required improvements by combining their functionalities into a new application called **Lingflix**, which helps users learn languages through movies and web series.

## Algorithm:

1. Select two existing applications, Netflix and Duolingo, for UX analysis.
2. Study their user interfaces, navigation patterns, features and interaction behaviors.
3. Identify the strengths and limitations of both applications based on usability and user experience.
4. Analyze Netflix's movie streaming features and Duolingo's language-learning features.
5. Identify opportunities to combine entertainment and language learning into a single application.
6. Design a new application named **Lingflix**, integrating movie streaming with language-learning functionalities.
7. Create a welcome screen introducing the application and its purpose.
8. Design a home screen with movie recommendations, language categories and search functionality.
9. Design a video player screen with contextual vocabulary explanations, pronunciation support and an option to save new words.
10. Apply consistent colours, typography, navigation and usability principles across all screens.
11. Review the redesigned interface for visual consistency and ease of use.

## Output:

Designed a three-screen mobile application interface named **Lingflix**, combining the functionalities of Netflix and Duolingo.

The application consists of:

- **Welcome Screen:** Introduces the application and explains its purpose of learning languages through movies and series.
- **Home Screen:** Displays popular movies, trending content, search functionality and language categories such as Spanish, French, German and Japanese.
- **Video Player Screen:** Provides movie playback along with contextual vocabulary explanations, word pronunciation, vocabulary saving and learning tips.
